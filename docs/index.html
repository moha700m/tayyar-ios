دعم تطبيق «تيّار»

«تيّار» أداة تقدير مساعدة تستخدم حساس المغناطيس في الآيفون لقياس المجال المغناطيسي وتقدير وجود حديد أو معدن داخل الجدار. لا يكشف الأسلاك الكهربائية وليس جهاز سلامة. افصل الكهربا من الطبلون واستخدم جهاز كشف احترافي قبل الخرم دايماً.

سؤال أو مشكلة: GitHub Issues · سياسة الخصوصية

Tayyar Support

Tayyar is an estimation helper that uses the iPhone magnetometer to measure the magnetic field and estimate nearby ferrous metal behind a wall. It does not detect electrical wires and is not a safety device. Always switch off the breaker and use a professional detector before drilling.
